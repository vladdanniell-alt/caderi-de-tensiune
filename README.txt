# Calcul căderi de tensiune – cabluri din cupru

Aplicație web statică (un singur fișier: index.html, fără build).

## Publicare pe Vercel
1. Creează un repository nou pe GitHub și încarcă fișierul `index.html`.
2. În Vercel: Add New -> Project -> Import Git Repository.
3. Framework Preset: Other; Build Command și Output Directory rămân goale.
4. Deploy.

(Alternativ: trage folderul dezarhivat direct în Vercel Dashboard sau rulează `vercel` în folder.)
